## 30 秒电梯介绍

**产品是什么**：基于 LangGraph + DeepSeek-V3 + RAG 的四智能体协同信用卡流失客户挽回系统。前端原型已完成 9 个页面的完整交互演示，覆盖预警发现→AI 分析→挽回执行→效果回流全业务闭环。

**给谁用**：运营管理者（看板监控）、客户经理（挽回执行）、数据分析师（效果分析）、系统管理员（数据管理）。

**核心价值**：
1. **四 Agent 流水线可视化** — 客户洞察→产品洞察→经营策略→营销执行，每步有推理链路和合规检查
2. **SLA 分级响应** — P0(4h)/P1(48h)/P2(7d)/P3(30d)，按 AUM×风险等级自动匹配
3. **全链路闭环** — 预警→分析→操作→联络→数据回流→策略迭代→看板刷新
4. **RAG 知识库** — 产品知识库+策略知识库+合规话术库，三库分离服务不同 Agent

## 🏗️ 系统架构概览

### 前端原型（已实现）

```
index.html（单文件，2200+ 行）
├── <style> — CSS 变量 + 全局样式 + 组件样式
├── <nav> — 顶部导航栏（Logo + 系统状态 + 用户信息）
├── <div.search-container> — 全局搜索（CIF/姓名/证件号）
├── <aside.sidebar> — 侧边栏（9 个导航项，3 个分组）
├── <main> — 主内容区
│   ├── page-dashboard — 运营看板
│   ├── page-alerts — 预警中心
│   ├── page-analysis — 智能分析（4-Agent 可视化）
│   ├── page-followup-detail — 挽回操作详情
│   ├── page-followup — 挽回跟踪列表
│   ├── page-batch — 批量任务
│   ├── page-import — 数据导入
│   ├── page-customers — 客户台账
│   └── page-flow — 架构总览
└── <script> — JS 导航 + 搜索 + 筛选 + 数据切换
```

### 后端架构设计（架构总览页展示）

```
数据源层 → RAG 知识库层 → Agent 流水线层 → 输出层
  │              │                │              │
  ├── 交易明细    ├── 产品知识库    ├── 客户洞察     ├── 风险评级
  ├── 客户画像    ├── 策略知识库    ├── 产品洞察     ├── 权益推荐
  ├── 产品持有    ├── 合规话术库    ├── 经营策略     ├── 策略方案
  └── 行为日志    └── (FAISS+BGE)  ├── 营销执行     └── 话术文本
                                   └── (LangGraph)
```
