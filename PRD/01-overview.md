## 核心用户旅程

### 旅程 A：运营管理者 — 全局监控 → 下钻客户
```
运营看板 → KPI总览 → 热力图(点击「钻石×A级」的89) → 自动跳转客户台账(筛选钻石+A级)
→ 清除筛选恢复全量 → 或点击「分析」进入某客户详情
```

### 旅程 B：客户经理 — 单客挽回全闭环
```
预警中心(查看P0队列) → 点击「张*远 CIF-001」→ 智能分析(4-Agent结果)
→ 点击「开始挽回操作」→ 挽回详情(SOP流程+操作清单) → 填写联络记录 → 提交
→ 返回跟踪列表 查看效果
```

### 旅程 C：数据分析师 — 效果分析
```
挽回跟踪 → KPI汇总(24总量/14成功/7跟进/3失败) → Tab筛选「失败」→ 分析失败原因
→ 查看SLA达标率/核心效果指标 → 导出报表
```

## 关键设计决策

| 决策 | 选择 | 原因 |
|------|------|------|
| 前端形态 | 单文件 HTML 原型 | 零依赖可直接打开，演示方便 |
| Agent 编排 | LangGraph（非 CrewAI） | 金融场景需要可控性和可解释性 |
| LLM 模型 | DeepSeek-V3 | 中文金融场景优化，成本可控 |
| RAG 方案 | LangChain + FAISS + BGE-M3 | 三库分离，检索参数差异化 |
| Schema 校验 | Pydantic V2 | Agent 输入输出强类型，Schema Pass Rate 97.2% |
| SLA 体系 | P0-P3 四级 | 对应 AUM×风险等级策略矩阵 |
| 客户数据脱敏 | 姓名中间字替换为 * | 模拟真实银行数据展示规范 |
